# Real-Time Collaborative Sync Engine

A simplified backend for real-time collaborative document editing, similar
to how Google Docs works behind the scenes.

## What this project does

Multiple users can edit the same document at the same time. Edits sync
instantly between everyone connected, work continues offline and merges
back in on reconnect, and every past version of the document is kept and
restorable.

## Tech Stack

Frontend: React, Tailwind CSS, CodeMirror
Backend: Node.js, Express, ws (WebSocket)
Database: MongoDB, Mongoose
Testing: Jest
Deployment: Render, Vercel, MongoDB Atlas

## Status

Work in progress — built step by step as a learning project.
